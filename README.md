# 🌍 Democratizing Financial Infrastructure with Cardano & Docker

This open-source repository provides a production-ready, fully containerized setup for deploying a **Cardano Node (Preview Testnet/Mainnet)** alongside a complete **Prometheus & Grafana monitoring stack**.

Designed for low-barrier, rapid deployment in emerging markets and developing regions where traditional banking infrastructure is scarce or non-existent.
